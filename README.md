# DTLCP_Wiresahrk
Wireshark插件，使wireshark支持解析DTLCP协议
##使用方式
本插件为适用于wireshark的lua插件，将该插件文件下载后放到wireshark的插件目录下即可。找到插件目录的过程如下：
![image](https://github.com/user-attachments/assets/5cf5c446-f278-4138-bc2c-fa4b4e8d44c2)
![image](https://github.com/user-attachments/assets/2db55da5-7e64-47bb-b2af-0487aeb13d56)
点击路径即可（如果是第一次点击会提示创建该文件夹，同意即可）
